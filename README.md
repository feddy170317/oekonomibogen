# Økonomibogen

En gratis økonomibog til familier: budget, månedens tal, sparemål, store regninger, gæld, investering og en 10-års plan.

**Åbn den her:** https://feddy170317.github.io/oekonomibogen/

## Dine tal er dine egne
- Alt, du skriver, gemmes kun i din egen browser på din egen enhed. Intet sendes nogen steder hen.
- Ryddes browserens data, eller skifter du enhed, er tallene væk. Brug knappen **Gem sikkerhedskopi** nederst på siden en gang imellem, og **Hent sikkerhedskopi** for at få dem tilbage.

Siden regner og forklarer. Den er ikke personlig økonomisk rådgivning.
